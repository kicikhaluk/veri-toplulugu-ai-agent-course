# Veri Topluluğu AI Agent

An educational course covering:

- **Prompt Engineering and Techniques**
- **Building an Agent from Scratch with Claude** — the agentic loop, evals, tool use

## Repo layout

- [`docs/`](docs/) — course site source, published via GitHub Pages
- [`src/`](src/) — code examples referenced by the course

## Course site

Once GitHub Pages is enabled (Settings → Pages → Source: `main` branch, `/docs` folder), the course site will be published automatically on every push to `main`.

To preview locally:

```bash
cd docs
bundle install
bundle exec jekyll serve
```
